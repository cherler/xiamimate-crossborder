# 虾米跨境 · 把账算清楚

> 利润、定价、广告账太烦，还老算错 —— **每一项成本都点得开，看得见它是你填的、抓来的，还是默认值。**

线上：**<https://xiamimate.com/crossborder>** · 平台首页：<https://xiamimate.com>

跨境电商的钱是被几十项小成本吃掉的：头程、尾程、FBA 分档、平台佣金、退款损耗、
广告占比、关税、增值税、计费重进位……单独看每一项都不大，合起来就是你以为在赚、
其实在亏。这个项目做的事很直白：**把这笔账摊开算，并且让每个数字都能追到它是怎么来的。**

## 五个算子

都是纯函数，`lib/crossborder/calculators/` 下面，**不依赖任何后端**：

| 算子 | 回答什么 |
|---|---|
| 利润计算器 | 这一单到底赚多少？保本价是多少？ |
| 定价决策模拟器 | 已知成本和目标净利率，该卖多少钱？ |
| 广告盈亏规划器 | ACoS 到几就不赚了？给定预算能跑多少单？ |
| 计费重与包装优化器 | 实重还是体积重收钱？改个包装能省多少？ |
| 进口到岸成本估算 | 货值 + 关税 + 增值税 + 头程，落地多少钱？ |

算子带 86 个测试，`npm test` 就能跑 —— 包括「英寸当公制填」这种真实踩过的坑：
同一组数按英寸和公制算，计费重差 25%。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:3000/crossborder
npm test         # 86 个算子测试
```

**算子部分开箱即用，不需要配置任何东西。**

## 哪些功能需要自建后端

这个仓是从平台里抽出来的前端。下面两处依赖后端 API，开源版里会退化成空态：

- **商品档案**（`app/crossborder/center.tsx`）—— 商品模型的云端保存与多设备同步
- **资讯流**（`app/crossborder/news-feed.tsx`）—— 行业资讯抓取

后端不在本仓（它和账号、计费、支付、运营台混在一起，那些不适合开源）。
要完整跑起来，你需要自己实现 `lib/api.ts` 里约定的那几个端点，或者直接用
<https://xiamimate.com/crossborder>。

## 它跟别的计算器有什么不一样

**不替你拍板。** 算完给的是一张摊开的账，不是一个"建议售价"。每一项成本旁边标着
它的来源：你自己填的、从商品档案带出来的、还是用了默认值 —— 默认值会明确标出来，
因为默认值最容易让人把别人的假设当成自己的结论。
